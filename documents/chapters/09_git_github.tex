\chapter{Git e GitHub}

Git è utilizzato per il versionamento del codice, mentre GitHub ospita il repository remoto sotto l'account proprietario \texttt{GiovanniGrigoli}. Il branch principale è \texttt{main}.

Il file \texttt{.gitignore} esclude file locali e artefatti generati, tra cui credenziali \texttt{.env}, ambienti virtuali Python, dipendenze Node, cache Python e build frontend. Il file \texttt{.env.example}, privo di segreti, può essere mantenuto nel repository come modello di configurazione.

Le modifiche vengono versionate con commit e inviate al repository remoto. I push su \texttt{main} attivano la pipeline automatica.
